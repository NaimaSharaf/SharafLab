Sequence · Domains · Topology · 3D

From sequence to topology.

Open one DSSP-processed CIF file to see its secondary structure residue by residue, find domains from the coordinates, draw a topology diagram, and view the chain in 3D. Every view uses the same domain colors, and each one downloads as a figure.

  1. Process your structure with DSSP first. Upload your .cif (or PDB) file to pdb-redo.eu/dssp and download the annotated mmCIF it returns.
  2. Open that DSSP-processed .cif file here. The sequence, domains, topology diagram and 3D view all read from it.

Select a residue to inspect its position and structure. Use left and right arrow keys to move along the sequence.

Element labels use CIF identifiers: α1 means alpha helix 1; β1 · A means strand 1 in sheet A. Hover over a label for the full identifier. Edited assignments are marked “Edited”. Coils represent helices: α-helices (H) and 3₁₀ / π helices (G, I) use separate colors; arrows represent E strands and B bridges. Other assignments appear as lines. Wrapped segments continue onto the next row; arrows point toward the C terminus. This is a sequence schematic, not a 3D structure.

Files are processed in your browser. No upload service or external libraries.

Domains

Residue ranges use the file's label numbering; separate pieces with commas (e.g. 1–10, 71–164). Helices take the domain color; strands use a lighter tint.

Residues in each domain

One-letter sequence of each domain, in residue order, with one entry for each continuous piece. Residues that are not in any domain are listed last.
