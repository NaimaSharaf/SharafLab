Figure library.

Arrows, bacteria, animal silhouettes and symbols for figures, each in its own section. Set the color, line width and size once, then copy any figure as SVG and paste it into Affinity, Illustrator or PowerPoint.

Check every result. These tools were vibe coded: built quickly with AI assistance and not independently validated. Compare their output with your own data and standard software before using it in figures, analyses or publications.

Arrow size

Size is the length of the arrow's main span. Line widths and arrowheads stay in pt whatever the size.

Bacteria

Double-click a bacterium (or click ✎) to change its own shape: spacing between cells, number of cells, tail waves and height, line width and more.

Bacteria use the color above, their own line width, and are sized by their overall width (the long spirochete is drawn longer so its waves match the standard one). Each membrane is a stroked shape, with the inner membrane inside the outer one; fills go on those shapes. If only the space between membranes is filled, the inside is filled white.

Animals

Every animal is one shape with smooth curves, scaled to the height you set. The bird, mouse, lizard, dog and human silhouettes were drawn by Naima Sharaf.

Symbols

Line symbols are strokes; the star, bolt and burst are filled shapes. Size is the width of the symbol's square.

Size and style

Each object or icon is one shape built from regular parts, with details cut out. Doors open from closed to wide open; flip ↔ to hinge one on the other side.

Direction

Set Document DPI to your Affinity document's DPI so pastes land at the right size; use 72 for Illustrator. Settings are remembered in this browser.
