Lab tools · Figures · Arrows

Arrow library.

Straight, curved, circular, elbow, reaction and inhibition arrows, plus bacterial cells (rods, cocci, spirochetes) for figures. Set the color, line width and size once, then copy any figure as SVG and paste it into Affinity, Illustrator or PowerPoint.

Check every result. These tools were vibe coded: built quickly with AI assistance and not independently validated. Compare their output with your own data and standard software before using it in figures, analyses or publications.

Cells

Double-click a cell figure (or click ✎) to change its own shape: spacing between cells, number of cells, tail waves and height, line width and more.

Cells use the color above, their own line width, and are sized by their overall width (the long spirochete is drawn longer so its waves match the standard one). Each membrane is a stroked shape, with the inner membrane inside the outer one; fills go on those shapes. If only the space between membranes is filled, the inside is filled white. Rotate, flip and DPI apply to cells too.

Size is the length of the arrow's main span. Line widths and arrowheads stay in pt whatever the size. Set Document DPI to your Affinity document's DPI so pastes land at the right size; use 72 for Illustrator. Settings are remembered in this browser.
