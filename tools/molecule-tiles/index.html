Lab tools · Chemistry · Figures

Tile chemical structures for a figure.

Type a CAS number, name or SMILES and press + to add each molecule. Structures come from PubChem and are drawn with the same bond length, font and 1 pt bonds, tiled across a 7 inch canvas. Drag any molecule to move it, click an empty spot to scale them all, add arrows from the library, then copy the result as SVG. The blank page below the tiled figure is a 7 × 7 inch canvas: click a molecule and press Ctrl/⌘ C, click the page and press Ctrl/⌘ V to reuse it there.

Check every result. These tools were vibe coded: built quickly with AI assistance and not independently validated. Check each structure against the original record, especially salts, charges and tautomers, before using it in a figure or publication.
